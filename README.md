# EconoSphere AI

**AI-Powered Economic Decision Intelligence Platform**

## Overview
A Digital Twin of the Global Economy capable of simulating economic crises, forecasting macroeconomic indicators, visualizing global trade relationships, and providing AI-powered policy recommendations.

## Repository Structure
- `apps/`: Next.js web frontend and FastAPI gateway
- `packages/`: Shared UI components, configurations, and types
- `services/`: Core backend modules (simulation, forecasting, policy, graph)
- `data/`: Datasets and database seeders
- `infrastructure/`: Docker and database setups
- `docs/`: Project documentation
